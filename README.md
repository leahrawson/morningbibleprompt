# Morning

A quiet, browser-based morning practice for Scripture, reflection, breath, and beginning the day.

## Privacy

Morning has no account system or database. Reflection text is stored in the visitor's browser using `localStorage` and is removed when the visitor chooses **Begin the day**. See `privacy.html` for the public-facing privacy notice.

## Publish with GitHub Pages

1. Create a public repository (for example, `morning`).
2. Add `index.html` and `privacy.html` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site will be available at the GitHub Pages URL shown in repository settings.

## Before a wider launch

- Decide whether the Verse of the Day remains curated/static or uses a licensed/API source.
- Consider self-hosting the fonts if you want to eliminate the Google Fonts request.
- Test keyboard navigation, screen-reader output, 200% zoom, reduced-motion mode, and mobile layouts.
- Add a custom domain and social preview image only if desired.
